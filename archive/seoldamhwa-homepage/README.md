# 설담화 메인페이지 시안

도라지꽃 판화와 세로 조판을 중심으로 구성한 정적 HTML/CSS/JavaScript 메인페이지입니다.

## 열기

index.html을 브라우저에서 열거나 간단한 정적 서버로 이 폴더를 실행합니다.

## 확인 전제

- 이미지들은 시안용 생성 이미지이며 실제 설담화 완성 제품 사진이 아닙니다.
- 헤더 카테고리는 메인페이지 안에서 이동합니다. 장바구니와 마이페이지는 안내 창으로 표시합니다.
- 메인 문구와 서체는 현재 구성안의 제안입니다.

## 이미지 생성 프롬프트 요약

첫 화면의 `assets/doraji-print.png`는 ImageGen으로 만들었습니다. 첨부 라벨을 참고해 남색 도라지꽃, 초록 잎, 겨자색 꽃술을 별색 인쇄와 점묘 질감으로 표현했습니다. 보자기 인장에는 기존 `assets/seoldamhwa-bojagi-mark.png`를 사용했습니다.

`assets/seoldamhwa-wordmark-fine.png`는 첨부 포스터 상단의 손글씨를 참고해 ImageGen으로 만든 투명 배경 로고입니다. ‘설담화’를 옅은 푸른색과 가늘게 빠지는 불규칙한 획으로 그렸습니다.

제품과 Works에는 코발트·아이보리 원단 포장, 꽃, 전통 매듭, 파우치를 담은 기존 `assets/concept-contact-sheet.png`의 일부를 사용했습니다.
